# Monorepo Setup

pnpm workspaces + Turborepo.

---

## Workspace layout

```
3ers/
├── apps/
│   ├── invite/       ← existing template (migrated from repo root)
│   ├── marketing/    ← landing page
│   ├── admin/        ← admin panel
│   └── portal/       ← client portal
├── packages/
│   ├── ui/           ← shared design tokens + components
│   ├── db/           ← Drizzle ORM schema + client + storage helper
│   └── config/       ← shared tsconfig, tailwind preset, eslint config
├── infra/
│   ├── docker-compose.yml
│   ├── docker-compose.dev.yml
│   ├── postgres/init.sql
│   └── minio/init.sh
├── platform/
│   └── docs/
├── pnpm-workspace.yaml
├── turbo.json
└── package.json      ← root (scripts only, no deps)
```

---

## pnpm-workspace.yaml

```yaml
packages:
  - 'apps/*'
  - 'packages/*'
```

## turbo.json

```json
{
  "$schema": "https://turbo.build/schema.json",
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": [".next/**", "dist/**"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    },
    "lint": {},
    "typecheck": {}
  }
}
```

---

## packages/db

```
packages/db/
├── package.json
├── src/
│   ├── client.ts       ← db singleton (Pool + Drizzle)
│   ├── schema.ts       ← all table definitions
│   └── storage.ts      ← MinIO S3 client + presigned URL helpers
├── migrations/         ← SQL files generated by drizzle-kit
└── drizzle.config.ts
```

`package.json` name: `@3ers/db`

Dependencies: `drizzle-orm`, `pg`, `@aws-sdk/client-s3`, `@aws-sdk/s3-request-presigner`

---

## packages/ui

```
packages/ui/
├── package.json
├── src/
│   ├── tokens.ts       ← re-export of DESIGN.md values as JS constants
│   ├── components/     ← shared shadcn components (Button, Card, Input, etc.)
│   └── index.ts
└── tailwind.preset.ts  ← Tailwind preset with brand colours + typography
```

`package.json` name: `@3ers/ui`

Apps import: `import { Button } from '@3ers/ui'`

Tailwind preset usage in each app's `tailwind.config.ts`:
```ts
import preset from '@3ers/ui/tailwind.preset'
export default { presets: [preset] }
```

---

## packages/config

```
packages/config/
├── package.json
├── tsconfig.base.json    ← shared TS settings
├── eslint.config.mjs     ← shared eslint rules
└── next-auth.d.ts        ← shared NextAuth type augmentation
```

`package.json` name: `@3ers/config`

Each app's `tsconfig.json`:
```json
{
  "extends": "@3ers/config/tsconfig.base.json",
  "include": ["src", "app", "components"]
}
```

```json
  "scripts": {

    "build": "turbo build",
    "lint": "turbo lint",
    "typecheck": "turbo typecheck",
    "db:generate": "pnpm --filter @3ers/db drizzle-kit generate",
    "db:migrate": "pnpm --filter @3ers/db drizzle-kit migrate",
    "docker:up": "docker compose -f infra/docker-compose.yml up -d",
    "docker:dev": "docker compose -f infra/docker-compose.yml -f infra/docker-compose.dev.yml up",
    "docker:down": "docker compose -f infra/docker-compose.yml down"
  }
}
```

## Migration plan for existing `apps/invite`

Current repo root IS the invite app. Steps to migrate:

1. `mkdir apps/invite`
2. Move `app/`, `components/`, `data/`, `public/`, `lib/`, `next.config.ts`, `tailwind.config.ts`, `tsconfig.json` → `apps/invite/`
3. Update `apps/invite/package.json` name to `invite`
4. Root `package.json` keeps only workspace scripts
5. Update `.gitignore` paths for new structure
6. Docker build context stays at repo root (needs all packages)

Do this migration AFTER the monorepo packages are set up, so the invite app can import from `@3ers/ui` and `@3ers/db`.
