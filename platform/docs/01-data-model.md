# Data Model

ORM: Drizzle ORM over PostgreSQL. All tables live in schema `public`. Migrations in `packages/db/migrations/`.

---

## Tables

### `users`
Auth table — both admin users and couple accounts.

```sql
id          uuid PRIMARY KEY DEFAULT gen_random_uuid()
email       text UNIQUE NOT NULL
password    text                        -- hashed; null if magic-link only
role        text NOT NULL               -- 'admin' | 'client'
created_at  timestamptz DEFAULT now()
```

### `orders`
One row per commissioned invitation.

```sql
id              uuid PRIMARY KEY DEFAULT gen_random_uuid()
client_id       uuid REFERENCES users(id)
status          text NOT NULL DEFAULT 'new'
                -- 'new' | 'in_review' | 'config_sent' | 'live' | 'archived'
template_id     uuid REFERENCES templates(id)
config_draft    jsonb                   -- editable by client, pending approval
config_live     jsonb                   -- admin-approved, deployed to invite
partner1_name   text
partner2_name   text
wedding_date    date
language        text DEFAULT 'fr'       -- 'fr' | 'ar' | 'en' | 'all'
created_at      timestamptz DEFAULT now()
updated_at      timestamptz DEFAULT now()
```

### `templates`
Versioned invitation template definitions.

```sql
id              uuid PRIMARY KEY DEFAULT gen_random_uuid()
name            text NOT NULL
version         text NOT NULL DEFAULT '1.0.0'
preview_url     text
config_schema   jsonb NOT NULL          -- field definitions + defaults
active          boolean DEFAULT true
created_at      timestamptz DEFAULT now()
```

### `rsvp_responses`
Guest RSVP submissions per order.

```sql
id              uuid PRIMARY KEY DEFAULT gen_random_uuid()
order_id        uuid REFERENCES orders(id)
guest_name      text NOT NULL
attending       boolean NOT NULL
meal_pref       text
message         text
created_at      timestamptz DEFAULT now()
```

### `guestbook_entries`
Guestbook messages, separate from RSVP.

```sql
id          uuid PRIMARY KEY DEFAULT gen_random_uuid()
order_id    uuid REFERENCES orders(id)
name        text NOT NULL
message     text NOT NULL
created_at  timestamptz DEFAULT now()
```

### `messages`
Internal thread between admin and each client.

```sql
id          uuid PRIMARY KEY DEFAULT gen_random_uuid()
order_id    uuid REFERENCES orders(id)
from_role   text NOT NULL               -- 'admin' | 'client'
body        text NOT NULL
read        boolean DEFAULT false
created_at  timestamptz DEFAULT now()
```

### `invoices`

```sql
id                  uuid PRIMARY KEY DEFAULT gen_random_uuid()
order_id            uuid REFERENCES orders(id)
amount_cents        integer NOT NULL
currency            text DEFAULT 'eur'
status              text DEFAULT 'unpaid'   -- 'unpaid' | 'paid' | 'refunded'
stripe_payment_link text
stripe_session_id   text
paid_at             timestamptz
created_at          timestamptz DEFAULT now()
```

### `assets`
Files uploaded to MinIO, referenced per order.

```sql
id              uuid PRIMARY KEY DEFAULT gen_random_uuid()
order_id        uuid REFERENCES orders(id)
type            text NOT NULL           -- 'couple_photo' | 'venue_photo' | 'other'
bucket          text NOT NULL
object_key      text NOT NULL           -- path inside MinIO bucket
original_name   text
size_bytes      bigint
uploaded_at     timestamptz DEFAULT now()
```

```sql
CREATE INDEX ON orders(client_id);
CREATE INDEX ON orders(status);
CREATE INDEX ON rsvp_responses(order_id);
CREATE INDEX ON guestbook_entries(order_id);
CREATE INDEX ON messages(order_id);
CREATE INDEX ON assets(order_id);
CREATE INDEX ON invoices(order_id);
```

## Drizzle schema location

`packages/db/src/schema.ts` — exports all table definitions.  
`packages/db/src/client.ts` — exports `db` singleton (Pool + Drizzle).  
`packages/db/migrations/` — SQL migration files generated by `drizzle-kit`.
